# 🎵 Lura Music Player - Public Releases

Welcome to the official public distribution repository for **Lura**, a modern, high-performance Android music streaming application designed for seamless audio playback, rich aesthetics, and lightweight resource usage.

---

## 🌟 Overview & Architecture

Lura delivers a fluid and responsive listening experience built on modern Material 3 design principles.

* **Client-Side Web Stream Parsing**: Lura processes public web audio streams and metadata client-side directly on your device. Audio streams are fetched and decrypted locally, ensuring low latency and privacy without routing user traffic through any intermediary servers.
* **Dynamic Accent Engine**: Complete user control over app aesthetics with real-time accent color customization and sleek dark/light mode options.
* **Lightweight & Battery Efficient**: Optimized native Kotlin architecture designed for low memory footprint and seamless background playback.

## 📦 Available Release Packages

Download the appropriate `.apk` build for your device architecture from the **[Releases](../../releases)** tab:

| Package | Target Architecture | Description |
| :--- | :--- | :--- |
| **`Lura-arm64-v8a-release.apk`** | 64-bit ARM (`arm64-v8a`) | **Recommended** for almost all modern Android smartphones & tablets. |
| **`Lura-armeabi-v7a-release.apk`** | 32-bit ARM (`armeabi-v7a`) | Optimized for older Android devices and lower-spec hardware. |
| **`Lura-x86_64-release.apk`** | 64-bit x86 (`x86_64`) | Intended for Android emulators, ChromeOS, and x86 Android devices. |
| **`Lura-universal-release.apk`** | Universal (`All ABIs`) | Multi-architecture package that installs on any compatible Android device. |

## 🚀 Installation Instructions

1. Go to the **[Latest Release](../../releases/latest)** section.
2. Select and download the `.apk` file corresponding to your device.
3. Open the downloaded file on your Android device and confirm installation *(enable "Install from Unknown Sources" if prompted)*.
4. Launch **Lura** and enjoy your music!
